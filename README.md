# For Kennar

A personal apology website from Shean to Kennar, adapted from the proven romantic blue apology flow and personalized with the customer data in `data.txt`.

## Run locally

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`. Run `npm run build` to create the static production version in `out/`.

The main letter is loaded from `letter.txt`. The customer photo is stored at `public/photos/kennar-memory.jpeg`, and Keep Me by Novo Amor is stored at `public/music/keep-me.mp3`. This version intentionally has no WhatsApp button.
